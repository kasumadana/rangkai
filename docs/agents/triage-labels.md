# Triage labels

| Canonical role | Local Status value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluates incoming issue |
| needs-info | needs-info | Required reporter input is missing |
| ready-for-agent | ready-for-agent | Self-contained ticket ready for delegated work |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

These values are local ticket statuses, not a request to create GitHub labels. Existing accepted task completion and native Orca lifecycle state remain separate from triage roles.
