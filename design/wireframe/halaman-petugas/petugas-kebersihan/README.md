# Halaman Petugas — Petugas Kebersihan (Cleanup Officer)

Layar wireframe low-fidelity khusus petugas kebersihan dengan izin tunggal `cleanup:update`. Mencakup pelaporan tugas, upload foto bukti sebelum dan sesudah, pencatatan kategori sampah secara jujur (berat terukur vs estimasi vs karung), serta penegasan bahwa laporan kebersihan tidak membuka jalan secara otomatis.
