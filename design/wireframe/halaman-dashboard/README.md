# Halaman Dashboard (Organizer Application)

Layar wireframe low-fidelity untuk penyelenggara resmi (Prajuru Banjar / Panitia Acara) setelah login. Berisi manajemen kegiatan, wizard pembuatan kegiatan 7 tahap, tinjauan ekstraksi AI (split-panel & mobile drawer), penugasan petugas, serta verifikasi kebersihan.
